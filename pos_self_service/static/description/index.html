SSP

POS Self-Service (Auto Service)

A lightweight self-service point of sale module for Odoo 18 — optimized for kiosks and unattended checkout flows.

Odoo 18 compatible
Version 1.0.0
License: AGPL-3

Turn any terminal into a self-service POS

This module provides a focused interface and helper workflows to run unattended sales: quick product selection, clear payment flows, receipt printing, and optional staff override.

UX
Clean kiosk interface
Touch-friendly, large buttons, and simplified navigation for customers.
Pay
Multiple payment methods
Support for cash, card terminals, and digital wallets (integrations via standard Odoo payment modules).
Cfg
Fast configuration
Minimal settings required to enable self-service mode and define allowed product categories.
Safe
Security & overrides
Staff override screens with PIN and configurable permissions to reduce misuse.

Benefits

  • Reduce queues and speed up checkout.
  • Lower staffing costs for repetitive retail tasks.
  • Flexible: works on tablets, touchscreens, or dedicated kiosks.

Quick install

Place the module folder in your Odoo addons path and update app list. Then install from Apps.

# as root of your odoo installation
cp -r pos_self_service /path/to/odoo/addons/
# restart Odoo and update apps

For advanced setup (hardware, card terminals) consult the module README or integration docs.

Get started

Install the module from the Apps menu, then navigate to Point of Sale → Configuration → Self-Service
