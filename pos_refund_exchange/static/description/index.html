Odoo POS Refund Exchange - Return and Replace Product in One Order

Restore the natural and practical product exchange workflow in Odoo Point of Sale. This module helps cashiers process a refund and immediately add a replacement product to the same order, improving customer service and reducing checkout friction.

It is built for businesses that need an Odoo POS refund exchange workflow, a quick return and replace process, and a reliable product exchange in POS experience for Odoo 19.

Why businesses need this module

In many retail and service operations, customers do not want a simple refund; they need a refund with replacement product. Standard Odoo flows can be too rigid for this type of transaction, especially when a customer returns an item and immediately selects another one.

This app fixes that by restoring the expected Odoo POS exchange flow: refund the returned product, add the new item on the same order, and settle the net difference correctly.

What this module does

  • After refund creation, the POS opens the product screen instead of sending the user directly to payment.
  • Allows the cashier to add a replacement product during the same Odoo refund workflow.
  • Maintains natural line signs for exchange transactions: returned products remain negative and replacement items remain positive.
  • Shows the correct net amount so the customer pays or receives the exact difference.
  • Prevents payment screen errors during the exchange flow when the order state is briefly unavailable.

Common use cases

  • Retail stores replacing defective products at checkout.
  • Electronics shops processing product exchange in POS after a return.
  • Fashion and accessory stores handling return and replace workflows quickly.
  • Operations that need a fast Odoo refund with replacement product instead of a pure refund.

Key features

  • Compatible with Odoo 19 Point of Sale.
  • Designed for Odoo POS refund exchange operations.
  • Correct financial behavior for customer balance and order totals.
  • Better user experience for cashiers during returns and product replacement.
  • Does not depend on localizations or country-specific modules.

Compatibility

This module is intended for Odoo 19 and works with the standard Point of Sale app. It restores the exchange workflow without depending on local country modules or duplicate overrides from other patches.

It is recommended not to install it together with duplicate exchange patches that override the same POS behavior, as this may load the same logic twice.
