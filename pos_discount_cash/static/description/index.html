Cash Payment Discount at Point of Sale

Module Description

This module provides a practical and effective solution for applying discounts when the customer pays in cash at the Point of Sale. Designed for Odoo POS, it allows you to configure automatic discount rules or apply them manually at the end of the sale, boosting sales and rewarding customers who use cash.

Benefits: increases checkout conversion, improves the shopping experience, and simplifies promotion management without technical complications. Easy installation and configuration so you can start seeing results from day one.

Install this module and turn every cash payment into an opportunity for customer loyalty and growth.
