POS Cash Control Permissions

Control de entrada y salida de efectivo en POS

Este módulo permite controlar quién puede retirar efectivo del POS, añadiendo un grupo de seguridad específico para retiros de efectivo.

Configuración

  1. Instale el módulo POS Cash Control Permissions
  2. Vaya a Ajustes → Usuarios → Usuarios y seleccione el usuario
  3. En la pestaña Permisos, busque el grupo Point of Sale / Cash Withdrawal y actívelo
  4. En la configuración del POS (Punto de Venta → Configuración), asegúrese de tener habilitado Control de Efectivo
  5. Abra una sesión de POS — el botón Cash In/Out estará disponible
  6. Los usuarios sin el permiso Cash Withdrawal verán el botón pero no podrán seleccionar Cash Out
  7. Consulte los movimientos en Punto de Venta → Cash Moves

Características

  • Grupo de seguridad "Cash Withdrawal" para controlar retiros
  • Botón "Cash Out" oculto para usuarios sin permiso
  • Validación en servidor y frontend
  • Registro de todos los movimientos de efectivo (entradas y salidas)
  • Registro fecha/hora, usuario, monto, motivo y sesión
  • Vistas para consultar y filtrar movimientos

Permisos

Grupo Descripción
POS User Puede ver movimientos de efectivo (solo lectura)
Cash Withdrawal Puede retirar efectivo y registrar movimientos
POS Administrator Acceso completo a todos los movimientos
